# Near Ambulance Service - Frontend Project

## Overview
**Near Ambulance Service** is a web-based frontend project designed to showcase a fast and reliable ambulance service platform. This project allows users to view available ambulances, locate nearby services, and see emergency contact options.  

> **Note:** This is a **frontend-only project**. All functionality is for demonstration purposes; no backend integration or database is included.

---

## Features

- **Home / Overview Page**
  - Displays key features and mission of the service.
  - Showcases user feedback and testimonials.

- **Map Page**
  - Search and locate nearby ambulances on a map.
  - Distance calculation display (demo layout only).

- **Requests Page**
  - Display ambulance requests in a table format.
  - Status labels: Pending, Approved, Rejected.
  - Modal popups for viewing and confirming requests (frontend-only).

- **Drivers / Ambulance Listing**
  - Displays all available ambulances in card format.
  - Emergency call button and contact buttons for demonstration.

- **Emergency Section**
  - Highlight urgent service information.
  - Red emergency call button for user attention.

- **Mobile Responsive**
  - Fully responsive design across desktop, tablet, and mobile.
  - Navbar and cards adjust layout on smaller screens.

- **Background & Styling**
  - Modern UI with background images and gradient overlays.
  - Semi-transparent cards to improve readability.

1. Clone or download the project folder.
